# RentBuddy

Trust-based social platform for real-world connections.

## Quick Start

```bash
# Install dependencies
npm install

# Start development
npm run dev

# Or with Docker
docker-compose up --build
```

## Scripts

- `npm run dev` - Start both backend and frontend
- `npm run build` - Build frontend for production
- `npm run db:migrate` - Run database migrations
- `npm run db:seed` - Seed database
- `npm run docker:up` - Start with Docker

## Architecture

- **Frontend:** React 18 + TypeScript + Vite + Tailwind CSS
- **Backend:** Express + TypeScript + Prisma ORM + SQLite
- **Design:** Premium glassmorphism UI with dark/light mode

## Environment Variables

See `.env.example` in each package for required configuration.
