## 🚀 Deployment Quick Steps

### 1. Local Development
```bash
# Terminal 1: Backend
cd packages/backend && npm run dev

# Terminal 2: Frontend
cd packages/web && npm run dev

# Open http://localhost:5173
```

### 2. Production Build
```bash
npm run build       # Build both
cd packages/web && npm run build  # Frontend dist ready
npm start           # Backend (in packages/backend)
```

### 3. Deploy
```bash
# Backend: Deploy to Node.js hosting
# Frontend: Deploy dist/ to CDN/static hosting
# Setup database: PostgreSQL
# Set environment variables
```
